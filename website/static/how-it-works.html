How luxafor works

A Python driver and internet health monitor for the Luxafor Flag USB LED device. It turns an idle desk gadget into a real-time glanceable connectivity indicator by probing DNS resolvers, computing a weighted health score, and driving the LED through HID or a remote webhook.

The Problem

The Luxafor Flag sits on your desk doing nothing useful. Its vendor software is limited to calendar-based notifications and manual color switching.

The Solution

A Python driver with a built-in health monitor that probes DNS resolvers every 1.5 seconds and maps connectivity to LED color through a 4-state machine with hysteresis.

The Payoff

Glanceable connectivity status. Green means fine. Yellow means degraded. Solid red means down. Blinking red means act now — you've been offline for 5+ minutes.

Architecture

Two control paths: local USB HID for direct hardware control, and remote HTTP webhook for network-attached devices. The monitor uses the local path.

HID Protocol

The Luxafor Flag communicates over USB HID with an 8-byte buffer. Byte 0 is the report ID (always 0x00). Byte 2 carries the color code as an ASCII value.

bytes(b'\x00\x00\x4f\x00\x00\x00\x00\x00')
ColorEnum NameHexASCII

Monitor State Machine

Four states with threshold-based transitions and 3-second hysteresis. DOWN escalates to CRITICAL after critical_after seconds (default 300).

Probe Flow

Every 1.5 seconds, TCP connect probes fire at three DNS resolvers concurrently. Results feed through a sliding window, weighted scoring, hysteresis, and finally drive the LED.

Install

Get up and running in three steps.

1

Clone the repo

Grab the source from GitHub.

git clone https://github.com/joeblackwaslike/luxafor.git cd luxafor
2

Install dependencies

Uses uv for fast, reproducible installs.

uv sync
3

Run the monitor

Start monitoring. Green means you're online.

luxafor monitor
